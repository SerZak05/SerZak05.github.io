# Для начинающих

Вводные задачи из соревнований Kaggle категории Getting Started: выживание пассажиров, цены на жильё, рукописные цифры, твиты о катастрофах, логический вывод по парам предложений и прогноз продаж магазинов.

## 1. Titanic - Machine Learning from Disaster

**Источник:** [Titanic - Machine Learning from Disaster](https://www.kaggle.com/competitions/titanic)

Предскажите, какие пассажиры выжили при крушении «Титаника», по записям о пассажирах: имя, возраст, пол и социально-экономический класс. В обучающих записях указан исход; для остальных пассажиров предскажите `Survived`: 1 или 0. Заявки оцениваются по accuracy.

## 2. Spaceship Titanic

**Источник:** [Spaceship Titanic](https://www.kaggle.com/competitions/spaceship-titanic)

Предскажите, каких пассажиров перенесло в другое измерение после столкновения корабля Spaceship Titanic с пространственно-временной аномалией, по записям из повреждённой компьютерной системы корабля.

## 3. House Prices - Advanced Regression Techniques

**Источник:** [House Prices - Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques)

Предскажите итоговую цену каждого дома по 79 признакам, описывающим жилые дома в Эймсе, штат Айова.

## 4. Digit Recognizer

**Источник:** [Digit Recognizer](https://www.kaggle.com/competitions/digit-recognizer)

Определите цифру на каждом из десятков тысяч изображений рукописных цифр. Классические изображения MNIST даны с уже извлечёнными признаками.

## 5. Natural Language Processing with Disaster Tweets

**Источник:** [Natural Language Processing with Disaster Tweets](https://www.kaggle.com/competitions/nlp-getting-started)

Предскажите, какие твиты рассказывают о реальных катастрофах, а какие нет, по размеченной вручную выборке из 10 000 твитов. В части твитов слова о бедствии употреблены метафорически, поэтому метка показывает, сообщает ли твит о катастрофе на самом деле.

## 6. Contradictory, My Dear Watson

**Источник:** [Contradictory, My Dear Watson](https://www.kaggle.com/competitions/contradictory-my-dear-watson)

Для каждой пары «посылка — гипотеза» поставьте метку 0 (следствие), 1 (нейтрально) или 2 (противоречие). Предложения даны на пятнадцати языках.

## 7. Store Sales - Time Series Forecasting

**Источник:** [Store Sales - Time Series Forecasting](https://www.kaggle.com/competitions/store-sales-time-series-forecasting)

Спрогнозируйте штучные продажи тысяч товаров в разных магазинах Corporación Favorita. Обучающие данные включают даты, сведения о магазине и товаре, акции и историю продаж.
