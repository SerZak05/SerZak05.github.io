# Простой классический табличный ML

Пять простых задач на табличные данные: первые три вводные из Getting Started и две задачи, которые ещё не публиковались.

## 1. Titanic - Machine Learning from Disaster

**Source:** [Titanic - Machine Learning from Disaster](https://www.kaggle.com/competitions/titanic)

**Datasets:** No dataset link provided by the source.

Предскажите, какие пассажиры выжили при крушении «Титаника», по данным о пассажирах: имя, возраст, пол и социально-экономический класс. В обучающей выборке известен исход для 891 пассажиров; для 418 пассажиров из тестовой выборки предскажите `Survived`: 1 или 0. Заявка оценивается по accuracy.

## 2. Spaceship Titanic

**Source:** [Spaceship Titanic](https://www.kaggle.com/competitions/spaceship-titanic)

**Datasets:** No dataset link provided by the source.

Предскажите, каких пассажиров перенесло в другое измерение после столкновения Spaceship Titanic с пространственно-временной аномалией, по записям из повреждённой компьютерной системы корабля.

## 3. House Prices - Advanced Regression Techniques

**Source:** [House Prices - Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques)

**Datasets:** No dataset link provided by the source.

По 79 признакам, описывающим жилые дома в Эймсе, штат Айова, предскажите итоговую цену каждого дома.

## 4. Competitive Data Science Course by Data Feeling

**Source:** [Competitive Data Science Course by Data Feeling](https://www.kaggle.com/competitions/competative-data-science-course-by-data-feeling)

**Datasets:** No dataset link provided by the source.

По историческим данным каршеринга о состоянии машин перед поломками определите тип поломки. Это мультиклассовая классификация: вид неисправности нужен, чтобы техническая бригада обходила машины, которые вероятнее выйдут из строя раньше.

## 5. Regression w/ a Tabular California Housing Dataset

**Source:** [Regression w/ a Tabular California Housing Dataset](https://www.kaggle.com/competitions/sch2-reg-2026-d3-2)

**Datasets:** No dataset link provided by the source.

Лёгкое табличное соревнование на синтетических данных California Housing с названными признаками реальных наблюдений. Тестовые метки не опубликованы.
