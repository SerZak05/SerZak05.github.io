# Simple–Medium ML Contest

Five introductory-to-intermediate machine learning tasks spanning text, images, and tabular data.

## 1. Natural Language Processing with Disaster Tweets

**Source:** [Natural Language Processing with Disaster Tweets](https://www.kaggle.com/competitions/nlp-getting-started)

**Check:** Checked at the source.

Build a model that predicts which tweets are about real disasters and which are not, using a hand-classified dataset of 10,000 tweets. Some tweets use disaster-related language metaphorically, so the model must distinguish real emergency reports from non-disaster usage.

## 2. OpenCV TF Project-1 Image Classification - Round 6

**Source:** [OpenCV TF Project-1 Image Classification - Round 6](https://www.kaggle.com/competitions/open-cv-tf-project-1-image-classification-round-6)

**Check:** Checked at the source.

Create a 4-class CNN image classifier for cow, elephant, horse, and spider. Predict labels for the test images and aim for at least 80% accuracy on the public test leaderboard.

## 3. Churn Prediction 2026

**Source:** [Churn Prediction 2026](https://www.kaggle.com/competitions/churn-prediction-hse-cv-master)

**Check:** Checked at the source.

Solve a binary classification problem for churn prediction: decide whether each example corresponds to a customer who will churn.

## 4. OLP_AI_MTA_Practice_1

**Source:** [OLP_AI_MTA_Practice_1](https://www.kaggle.com/competitions/olp-ai-mta-practice-1)

**Check:** Checked at the source.

Each row is an independent transaction with 28 anonymized numeric features. The training label `target` is 0 for a normal transaction and 1 for a risky one that should be detected. For each test transaction, predict `fraud_probability` in [0, 1], where values closer to 1 mean the model is more confident the transaction is risky.

## 5. Contradictory, My Dear Watson

**Source:** [Contradictory, My Dear Watson](https://www.kaggle.com/competitions/contradictory-my-dear-watson)

**Check:** Checked at the source.

Build a natural language inference model that labels each premise–hypothesis pair as 0 (entailment), 1 (neutral), or 2 (contradiction). Train and test text cover fifteen languages.
