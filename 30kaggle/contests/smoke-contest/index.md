# Smoke contest

A short smoke-test contest of a simple classification tasks.

## 1. Digit Recognizer

**Source:** [Digit Recognizer](https://www.kaggle.com/competitions/digit-recognizer)

**Datasets:**

- [sample_submission.csv](https://www.kaggle.com/competitions/digit-recognizer/data?select=sample_submission.csv)
- [test.csv](https://www.kaggle.com/competitions/digit-recognizer/data?select=test.csv)
- [train.csv](https://www.kaggle.com/competitions/digit-recognizer/data?select=train.csv)

Given 28×28 grayscale images of handwritten digits 0–9, predict the digit label for each image. Evaluation is categorization accuracy (the proportion of test images classified correctly).
