# Как сдать свою первую задачу на Kaggle

## 1. Зарегистрироваться на [kaggle.com](https://www.kaggle.com/)

## 2. Открыть задачу, которую хотите сдать

Например, [Титаник](https://www.kaggle.com/competitions/titanic).

## 3. Создать ноутбук (Jupyter Notebook)

В нём вы будете писать решение. Ноутбук можно создать локально на компьютере (**вариант а**) или на самом Kaggle (**вариант б**).

- **а)** Для локальной работы рекомендуется использовать VS Code. После установки необходимо поставить расширение для работы с Jupyter Notebook и Python.
- **б)** Kaggle предоставляет всем пользователям 30 часов в неделю вычислений с GPU. Это очень полезно, когда нужно обучить модель, но локальных мощностей не хватает. Будьте осторожны: учитывается всё время работы с подключённым GPU, а не только время активного выполнения программы, поэтому **не забывайте отключаться от Kaggle**.

## 4. Загрузить данные

- **а)** Откройте раздел *Data* в задаче, скачайте все данные (архивом или по файлам) и положите в рабочую папку с кодом.
- **б)** Добавьте задачу в качестве *Input* к вашему ноутбуку.

После этого данные можно использовать в ноутбуке, например, загрузив через pandas: `pd.read_csv("...")`.

## 5. Обработать данные

Необходимо убрать отсутствующие значения (*NaN*), закодировать нужным образом признаки (категориальные признаки → one-hot encoding, бинарные признаки → 0/1 и т. п.), отделить target от остальных признаков, нормализовать данные. Также рекомендуется разделить train-данные на train/val, чтобы локально можно было проверить качество модели. Разные модели могут подразумевать разную обработку данных (например, *CatBoost* сразу может обрабатывать численные, категориальные и текстовые признаки — нужно лишь сказать ему типы, а также *NaN*).

## 6. Обучить модель

Модель можно выбирать из библиотеки `sklearn`; позже мы научимся конструировать нейронные сети при помощи `torch` и использовать готовые.

В `sklearn` все модели обучаются с помощью метода `.fit(X_train, y_train)`, где `X_train` — таблица train-признаков, `y_train` — столбец или Series с target. **Важно, чтобы строки `X_train` и элементы `y_train` соответствовали друг другу!**

Также можно использовать другие библиотеки (CatBoost и т. п.).

**Пример:**

```python
clf = catboost.CatBoostClassifier(iterations=100, cat_features=["eye_color"])
clf.fit(train_features, train_target)
```

## 7. Получить предсказание на тесте или замерить качество на валидации

Чтобы получить ответ, который можно отправить в Kaggle, или самостоятельно оценить качество модели, нужно предсказать target на выборке, которую модель ещё не видела (test или validation). **Будьте внимательны: с этой выборкой вы должны были сделать те же преобразования, что и с обучающей выборкой**, иначе предсказания могут оказаться плохими или вовсе получится ошибка.

После получения предсказаний можно либо сохранить результат и отправить его, либо замерить качество модели.

В `sklearn` это делается с помощью метода `predict`. **Пример:**

```python
predicted_val_target = clf.predict(val_features)
accuracy = (predicted_val_target == val_target).mean()

predicted_test_target = clf.predict(test_features)  # на выходе — np.ndarray
pd.Series(predicted_test_target).to_csv("...")  # чтобы сохранить в CSV, сначала преобразуйте в pandas
```

Возможно, вам потребуется преобразовать выход к формату, который задан в условии задачи. **Будьте осторожны: не перемешайте случайно ответы!**
