# Как сдать свою первую задачу на kaggle

1. Зарегистрироваться на [kaggle.com](https://www.kaggle.com/)

2. Открыть задачу, которую хотите сдать

3. Создать ноутбук (jupyter notebook), в котором будете писать решение. Ноутбук можно создать у себя локально на компьютере (вариант а) или на самом kaggle (вариант б).
