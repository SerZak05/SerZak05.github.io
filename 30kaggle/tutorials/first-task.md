# Как сдать свою первую задачу на kaggle

1. **Зарегистрироваться на [kaggle.com](https://www.kaggle.com/)**

2. **Открыть задачу, которую хотите сдать (например, [Титаник](https://www.kaggle.com/competitions/titanic))**

3. **Создать ноутбук (jupyter notebook), в котором будете писать решение. Ноутбук можно создать у себя локально на компьютере (вариант а) или на самом kaggle (вариант б).**
  *а)* Для локальной работы рекумендуется использовать VSCode. После установки необходимо установить расширение для работы с jupyter notebook и python.  
  *б)* kaggle предоставляет всем пользователям 30 часов в неделю вычислений с GPU. Это очень полезно, когда нужно обучить модель, но локальных мощностей не хватает. Будьте осторожны: учитывается всё время работы с подключённым GPU, а не только время активного выполнения программы, поэтому **не забывайте отключаться от kaggle**.

4. **Загрузить данные**
  *а)* Откройте раздел *Data* в задаче, скачайте все данные (архивом или по файлам), положите в рабочую папку с кодом.
  *б)* Добавьте задачу в качестве *Input* к вашему ноутбуку.
  После этого данные можно использовать в ноутбуке, например, загрузив через pandas: `pd.read_csv("...")`.

5. **Обработать данные**
  Необходимо убрать отсутствующие значения (*NaN*), закодировать нужным образом признаки (категориальные признаки -> onehot encoding, бинарные признаки -> 0/1 и т.п.), отделить target от остальных признаков, нормализовать данные. Также рекомендуется разделить train данные на train/val, чтобы локально можно было проверить качество модели. Разные модели могут подразумевать разную обработку данных (например, catboost сразу может обрабатывать численные, категориальные и текстовые признаки, нужно лишь сказать ему типы, а также *NaNs*).

6. **Обучить модель**
  Модель можно выбирать из библиотеки `sklearn`, позже мы научимся конструировать нейронные сети при помощи `torch` и использовать готовые.

  В `sklearn` все модели обучаются с помощью метода `.fit(X_train, y_train)`, где `X_train` - таблица train признаков, `y_train` - строка из target. Важно, чтобы строки `X_train` и элементы `y_train` соответсвовали друг другу!

  Также можно использовать другие библиотеки (catboost, и т.п.), всё, что найдёте.

  Пример:
```
clf = catboost.CatBoostClassifier(iterations=100, cat_features=["eye_color"])
clf.fit(train_features, train_target)
```

7. **Получить предсказание на тестовой выборке/замерить качество на валидационной выборке**
  
  Чтобы получить ответ, который можно отправить в kaggle или самостоятельно оценить качество полученной модели нужно с помощью неё предсказать target на выборке, которую модель ещё не видела (test или validation). **Будьте внимательны: с этой выборкой вы должны были сделать те же преобразования, что и с обучающей выборкой**, иначе предсказания могут оказаться плохими или вовсе получится ошибка.

  После получения предсказаний можно либо сохранить результат и отправить его, либо замерить качество модели.

  В `sklearn` это делается с помощью метода `predict`. Пример:
```
predicted_val_target = clf.predict(val_features)
accuracy = predicted_val_target == val_target

predicted_test_target = clf.predict(test_features) # На выходе получется np.ndarray
pd.Series(predicted_test_target).to_csv("...") # Чтобы сохранить в csv нужно сначала преобразовать в pandas 
```

  Возможно, вам потребуется преобразовать выход к формату, который задан в условии задачи. **Будьте осторожны: не перемешайте случайно ответы!**
